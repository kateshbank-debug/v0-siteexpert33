# Сайт Ивана Швейкина - Эксперт по организационным изменениям

Профессиональный сайт-визитка для эксперта по организационному развитию и трансформации бизнеса.

## Особенности

- 🎨 Минималистичный дизайн в стиле piethurkmans.com
- 📱 Полностью адаптивный (desktop 1200px, mobile 360px/480px)
- ⚡ Построен на Next.js 15 с App Router
- 🎭 Плавные анимации при скролле
- 🌐 Поддержка кириллицы (шрифты Montserrat + Cormorant Garamond)
- 📧 Интеграция с WhatsApp для отправки заявок
- 🗺️ Встроенная карта Google Maps
- 🎯 SEO оптимизация

## Структура сайта

- **Главная** - Hero секция с призывом к действию
- **Услуги** - Описание методов трансформации компании
- **Об эксперте** - Биография, опыт, отзывы клиентов
- **Блог** - Вопросы и ответы в формате Q&A
- **Контакты** - Форма обратной связи, контактная информация, карта

## Технологии

- Next.js 15
- React 19
- TypeScript
- Tailwind CSS v4
- Shadcn/UI компоненты
- Google Fonts (Montserrat, Cormorant Garamond)

## Установка и запуск

\`\`\`bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev

# Сборка для продакшена
npm run build

# Запуск продакшен версии
npm start
\`\`\`

Сайт будет доступен по адресу [http://localhost:3000](http://localhost:3000)

## Развертывание

### Vercel (рекомендуется)
1. Подключите репозиторий к Vercel
2. Vercel автоматически определит Next.js проект
3. Нажмите Deploy

### Другие платформы
Проект можно развернуть на любой платформе, поддерживающей Next.js:
- Netlify
- AWS Amplify
- Railway
- Render

## Панель управления

Для управления контентом (блог, отзывы, фотографии) рекомендуется интегрировать CMS:
- Netlify CMS (бесплатно, интеграция с GitHub)
- Sanity.io (бесплатный тариф)
- Contentful (бесплатный тариф для малых проектов)

Страница `/admin` содержит инструкции по интеграции CMS.
